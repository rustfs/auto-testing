# Agent and contributor guidance

Subsequent pull requests must use English.

Write these in English:

- Commit messages, both the subject and the body
- Pull request titles and descriptions
- Comments, documentation, and user-facing strings that a pull request adds or edits

Leave non-ASCII and CJK strings in place when they are test fixtures that exercise encoding. That includes object keys, payloads, journal samples, and similar inputs. Do not translate or replace them.
